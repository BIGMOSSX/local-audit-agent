Mac 检查包 — 怎么用（二选一）

【方式一：交给 Codex，最省事】
  1. 解压 zip。
  2. 打开终端，输入 cd 加一个空格，把 audit-mac-check 文件夹拖进终端，回车。
  3. 输入 codex 回车，启动后对它说：开始
  它会自己跑完（30–60 分钟），最后把报告贴出来，你把报告发回给我们。

【方式二：自己点】
  1. 解压 zip，双击 1-run-checks.command。
     被系统拦截的话：终端里输入 xattr -dr com.apple.quarantine 加空格，把整个文件夹拖进去回车，再双击。
  2. 跑完后报告已复制到剪贴板，粘贴发给我们。

两种方式都：
  - 只运行本包里的代码，不联网上传任何东西，不读账号密码令牌。
  - 缺 Node/pnpm/Rust 会下载到本文件夹的 .tools，不需要管理员密码。可能弹一次“安装 Xcode 命令行工具”，
    需要你本人点“安装”，装完重新来一次。
  - 结束后删除整个文件夹即可清理。报告里会带本机路径（含用户名）。

桌面部分（也是一键）：
  - 双击 3-auto-desktop-check.command：自动检查后台服务（项目识别、权限、令牌、重启/崩溃恢复等），
    约 1 分钟，报告同样已复制到剪贴板。
  - 想连窗口一起看：双击 2-open-desktop.command，再按 MANUAL-CHECKLIST.md 里的 5 项看一眼
    （只有这 5 项需要人眼）。
